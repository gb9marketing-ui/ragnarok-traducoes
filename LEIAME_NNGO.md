# Ragnaruto (NNGO no rAthena)

Arquivos do servidor NNGO convertidos para o rAthena (pré-renovação, cliente 2025-06-04).
A pasta `servidor/` contém só o que muda em relação ao rAthena original (commit d4b8e7b).

Para instalar numa VPS Ubuntu 24.04 (como root):

    curl -sL https://raw.githubusercontent.com/gb9marketing-ui/ragnarok-traducoes/nngo/instalar_nngo.sh -o instalar_nngo.sh
    bash instalar_nngo.sh

As senhas do banco de dados ficam só na VPS, em /root/nngo-credenciais.txt.
