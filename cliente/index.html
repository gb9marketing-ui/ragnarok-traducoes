Ragnaruto

Naruto New Generation · cliente provisório para Windows

BAIXAR O JOGOarquivo .zip · cerca de 6 GB
  1. Extraia o zip numa pasta, por exemplo C:\Ragnaruto. Não abra o jogo de dentro do zip.
  2. Abra o Ragnaruto.exe. Se der erro, clique nele com o botão direito e escolha Executar como administrador.
  3. Para criar a conta, digite no usuário o nome que quiser + _M (ou _F), por exemplo naruto_M, e uma senha. Depois entre só com naruto.
  4. Dentro do jogo, fale com a Anko para começar sua história ninja.

Servidor: __IP__ · Se o Windows avisar sobre o arquivo, clique em "Mais informações" e depois em "Executar assim mesmo".
